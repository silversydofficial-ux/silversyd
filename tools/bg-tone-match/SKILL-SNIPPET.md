### 배경 검수 수치 기준 (2026-09-22 추가)

위 프롬프트 규칙만으로는 "약간 다르다"를 매번 눈으로 판단해야 하므로, 검증 가능한 수치를 같이 둔다.

**합격 기준** — 배경 영역(피사체 제외) 평균값 기준:

| 항목 | 기준 | 불합격 시 증상 |
|---|---|---|
| 평균 밝기 | **220.7 ± 4** | 너무 밝으면 상품 리스트에서 카드 경계가 사라짐 |
| 틴트 \|R−B\| | **2 이하** | 배경이 푸르스름하거나 누렇게 뜸 |
| 순백 | **240 이상 금지** | 흰 배경끼리 붙어 카드가 붕 떠 보임 |

기준값 출처: 위 "톤 비교 기준 샘플"(`hf_20260914_122839_b88186f3...png`)의 실측값.

**검수 방법** — 실버시드 저장소의 `tools/bg-tone-match/` 도구 사용:

```bash
# 생성 직후 검수 (측정만, 파일 안 씀). 힉스필드 결과 URL을 그대로 넣으면 된다
python3 tools/bg-tone-match/bg_match.py --check <URL> ...

# 불합격분 보정
python3 tools/bg-tone-match/bg_match.py --outdir out <URL> ...
```

**불합격일 때 판단 기준:**

- **톤만 어긋남**(명도·틴트) → **재생성하지 말고 후보정.**
  배경 픽셀에만 톤을 정렬시키므로 인물·제품 픽셀이 전혀 바뀌지 않는다.
  얼굴/제품 색 드리프트 위험이 없고, 크레딧도 안 든다.
- **구조적 문제** → 이때만 힉스필드 재생성.
  배경의 동심원/링 무늬, 짐 배경 잔상, 인물에 박힌 진한 캐스트 섀도가 해당된다.
