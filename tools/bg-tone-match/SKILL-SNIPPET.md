### 배경 검수 수치 기준 (2026-09-22 측정 추가)

프롬프트 문장만으로는 "약간 다르다"를 매번 눈으로 판단해야 하므로, 검증 가능한 수치를 같이 둔다.
측정·보정 도구: `tools/bg-tone-match/bg_match.py` (실버시드 저장소)

합격 기준 (배경 영역 평균):
- 평균 밝기 **220.7 ± 4**
- **|R−B| ≤ 2** — 웜/블루 틴트 없음
- 순백(240 이상) 금지 — 상품 리스트에서 흰 배경끼리 경계가 사라져 카드가 붕 떠 보임

생성 직후 검수:
```bash
python3 tools/bg-tone-match/bg_match.py --check <힉스필드 결과 URL>
```

불합격이고 배경이 이미 심리스라면 **재생성하지 말고 후보정**한다.
인물·제품 픽셀이 전혀 바뀌지 않으므로 얼굴/제품 색 드리프트 위험이 없다:
```bash
python3 tools/bg-tone-match/bg_match.py --outdir out <URL> ...
```

재생성이 필요한 경우는 **구조적 문제**뿐이다 — 배경의 동심원/링 무늬, 짐 배경 잔상,
인물에 박힌 진한 캐스트 섀도. 톤(명도·틴트)만 어긋난 것은 후보정 대상이다.
