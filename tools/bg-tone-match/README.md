# 배경 톤 매칭 (상품 상세컷)

이미 생성된 스튜디오 상세컷의 **배경 톤만** 확정 규칙에 맞춰 보정한다.
브랜드 스킬 `silversyd-brand/references/ai-model-guide.md` 의
"상품 상세컷 고정 배경 규칙"(2026-09-14 확정)과 짝을 이루는 도구다.

## 왜 재생성 대신 후보정인가

| 방법 | 인물/제품 보존 | 비용 | 재현성 |
|---|---|---|---|
| 힉스필드 재생성 | 얼굴·제품 색이 드리프트 | 크레딧 소모 | 비결정적 |
| 배경 제거 후 합성 | 머리카락 엣지 손상, 접지 그림자 소실 | 크레딧 소모 | 보통 |
| **이 도구** | **픽셀 단위로 무변경** | **0** | **결정적** |

배경이 이미 심리스인데 톤만 어긋난 경우에는 이 도구가 가장 안전하다.
배경에 링 무늬·짐 배경 잔상 같은 **구조적** 문제가 있으면 이 도구로는 못 고치므로
그때만 힉스필드에서 재생성한다.

## 동작 방식

1. 저채도 + 충분히 밝음 + 이미지 테두리와 연결됨 → 배경으로 판정해 소프트 마스크를 만든다.
   피사체 안쪽의 밝은 영역(흰 신발, 로고 등)은 테두리와 끊겨 있어 마스크에서 빠진다.
2. 배경 픽셀에만 채널별 평균·표준편차를 기준값에 정렬시킨다.
   - 웜/블루 틴트가 사라지고 (R=G=B)
   - 명도가 기준과 맞으며
   - 바닥 그라데이션과 접지 그림자 구조는 살아남는다 (게인을 0.6~1.6로 제한)
3. 마스크를 3px 가우시안으로 풀어 경계에 띠가 생기지 않게 합성한다.

## 사용법

```bash
pip install pillow numpy scipy

# 측정만 (합격/불합격 판정, 파일 안 씀)
python3 bg_match.py --check <이미지|URL> ...

# 보정본 생성
python3 bg_match.py --outdir out <이미지|URL> ...

# 기준 샘플을 직접 지정해 타겟값을 실측
python3 bg_match.py --ref 기준.png --outdir out <이미지> ...
```

힉스필드 결과 URL(`https://d8j0ntlcm91z4.cloudfront.net/...`)을 그대로 넣어도 된다.

## 합격 기준

- 배경 평균 **220.7 ± 4**
- **|R−B| ≤ 2** (웜/블루 틴트 없음)
- 순백(240+) 금지 — 상품 리스트에서 흰 배경끼리 경계가 사라져 카드가 붕 떠 보인다

기본 타겟값은 `ai-model-guide.md` 의 "톤 비교 기준 샘플"을 이 도구의 마스크 기준으로
실측한 값이다. 기준 샘플이 바뀌면 `--ref` 로 재측정해 `DEFAULT_TARGET_*` 를 갱신한다.

## 주의

채널별 평균은 반드시 float64로 누적한다. float32로 채널축(비연속 스트라이드) 평균을 내면
수백만 픽셀에서 누적 오차가 수 단위로 쌓여 틴트 판정이 조용히 틀어진다.
