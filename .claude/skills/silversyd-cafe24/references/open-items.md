# 남은 일 (261009 스냅샷)

이 목록은 시간이 지나면 틀린다. 작업을 시작하기 전에 사용자에게 "이 중 어디까지 진행됐는지" 확인하고, 라이브로 실제 상태를 본다.

## 개편 진행 중 (시안 단계, 사용자 선택 대기였음)

1. **로그인/가입:** 적용 코드 v1, v1.1, v1.2, v1.3(가입 SNS 3개) 순서로 전달. v1.2 붙여넣기 여부 확인 필요. 실제 계정으로 SNS 가입 완료 플로우는 사용자 테스트 필요.
2. **약관:** 이용약관, 개인정보처리방침, 청약철회 수정안 전달. 부칙 시행일 임시값, 택배사, PG사 등 입력칸 사용자 확인. 편집기에서 인라인 스타일이 유지되는지 저장 후 라이브 확인.
3. **리뷰 페이지(board 4):** A+D 합친 안 추천, 버튼 모양(pill vs 10px) 선택 대기. PRO 해지 확정 후 4번 게시판 기반으로 개발. 구매 사이즈와 핏 정보는 작성 폼에 JS 선택칸을 추가해 본문 첫 줄 태그(`[구매 사이즈: L | 체감: 딱 맞아요]`)로 저장하고 표시 화면에서 파싱하는 방식으로 합의. 기존 후기 2건은 수동.
4. **상품 상세 후기 탭:** 모바일 3화면, PC 3안 시안. 「자주 나온 말」 삭제 반영.
5. **헤더:** H1(아이콘만, 추천), H2(로고 가운데), H3(혜택 띠) 중 선택 대기. 모바일에 장바구니 추가 포함. 상세헤더 시안과 높이, 아이콘 통일 필요.
6. **모바일 상세 상단:** 첫 갤러리 사진 `loading="lazy"` 제거 + fetchpriority high 등 공통 로딩 개선 + 헤더안 B(한 줄 흰 헤더) 추천, 선택 대기.
7. **후기 색상 통합:** 색상만 다른 상품끼리 후기 묶어 보여 주기. PRO 해지 기준으로 4번 게시판 데이터로 직접 구현.

## 관리자에서 사용자가 할 일
