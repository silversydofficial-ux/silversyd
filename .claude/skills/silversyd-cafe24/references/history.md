# 작업 이력과 전례 (요약)

비슷한 증상이 다시 나오면 여기서 먼저 찾는다. 차수는 전달 파일 번호다.

## 48차까지 (~260930): 메인, 카테고리, 상세 리뉴얼

상품카드 퀵애드, 색상 스와치, 사이드바, 메인 섹션 전체, PAIR YOUR SET, 상세 2단 레이아웃, 갤러리 스와이프, 헤더/푸터, 호버 크로스페이드, 스크롤 등장, 스켈레톤이 모두 이때 들어갔다. layout.html 정리본(197KB 를 154KB 로) 은 실전송량 차이가 gzip 83KB 대 75KB 로 작아 보류했다. 나중에 CSS/JS 를 외부 파일로 옮길 때 한 번에 하기로.

## 버그 전례 (증상 > 원인 > 해결)

- **모바일 상세 「배송/교환/환불 안내」 눌러도 무반응 (74차)** > 1024 이하는 `#tabProduct` 탭 구조라 `#prdInfo` 가 display none, `#guide` 앵커가 숨은 곳을 가리킴 > 클릭 시 구매안내 탭을 먼저 누르고 탭바 위치(헤더 56px 보정)로 스크롤.
- **셋업 카드에 10% 가 두 번 (59차)** > 우리 주입 스크립트가 먼저 소비자가 줄을 넣자 기존 메인 리뉴얼의 markSpec 이 그걸 보고 자기 할인율을 또 만듦 > `.ssd-off` 중 첫 번째만 남기는 정리 2줄. 교훈: 목록 카드 주입형 패치는 항상 중복 제거 포함.
- **메인만 카드 간격이 다름 (58차)** > `ssd-main` 클래스가 `<html>` 에 붙어 있어 `html .ssd-main ...` 이 영원히 매칭 안 됨 > 클래스 반복 트릭으로 명시도 올림.
- **롱티 카드가 메인에서 사라짐 (60차)** > getCards 번호 목록을 바꿨는데 sessionStorage 10분 캐시가 옛 목록 > 캐시 키 `ssd-main-cards-v1` 을 `v2` 로. 교훈: 번호 목록 바꾸면 캐시 키도.
- **찾기 0건으로 적용 실패 (60차)** > 앵커에 괄호(`getCards([`) > 괄호 없는 한 줄 앵커.
- **카테고리 스크롤 시 콘솔 "reading 'top'" (56차)** > 스킨 normalmenu.js 무한스크롤이 없는 `.xans-product-listmore` 의 offset 을 읽음 > length 가드.
- **태블릿(761~1000) 상세설명 4포인트가 소재 섹션까지 넘침** > 그리드 칸 최소폭 > `minmax(0,...)`, body 끝 주입(head 주입은 무효였음).
- **사파리에서만 소재 섹션 글자 침범** > WebKit 이 그리드 안 aspect-ratio 사진 줄 높이를 낮게 계산 > 모바일 flex column + figure 높이 지정. 교훈: 크롬과 WebKit 둘 다 검증.
- **모바일 디테일 캡션이 다음 줄 사진에 가려짐** > figure 높이 = img > `.sd__proof img{height:auto}`.
- **상세설명 제목과 본문 간격 0** > `.sd p{margin:0}` 리셋이 명시도로 본문 여백을 이김 > 리셋을 `:where()` 로.
- **구매 고정바가 상세설명 아래로 깔림** > `.ssd-pdp > .infoArea` sticky 쌓임맥락 > z-index 50.
- **주문완료 로고 앞 두 글자를 뒤로가기 화살표가 덮음 (49차)** > 주문서 전용 CSS `h1.xans-layout-logotop{margin-left:40px}` > 그 페이지 맨 위에 보정 CSS.
- **셋업 모바일만 스키마 가격이 "47,700원" 문자열 (61차)** > 카페24 출력 버그 > 코드 B enrichOffer 에서 숫자 정규화.
- **로그인 PC 비회원 주문조회에서 화보와 폼 높이 불일치** > `#wrap overflow:hidden` 이라 sticky 무효 > 768 이상 stretch 로 화보가 폼 높이를 따라감. 화보와 푸터 사이 흰 여백은 `.footer_margin` 100px.
- **비회원 구매 버튼이 사라짐** > 이전 코드가 `.login__button .btnNormal` 을 숨겼음 > `?noMember=1` 일 때 외곽선 버튼으로 노출.
- **같은 숫자에 취소선** > 소비자가 값이 판매가와 같아도 입력돼 있으면 카페24가 취소선 줄 출력 > 관리자에서 소비자가 비우기, 스크립트는 소비자가 <= 판매가면 숨김.
- **이용약관 제6조②2호~제24조 105줄 중복** > 라이브 약관 원문 중복 > 첫 제24조에서 끊은 수정안.

## 확정된 결정

- 탭(카테고리 1024 이하)은 A안 라인 탭. 할인 표기는 비율 「10%」, 색 빨강 유지.
- 카테고리 모바일 사진 전환은 E안(손으로 넘기기). 페이드 효과는 반려.
- 상세설명은 공통 u1 골격으로 16개 상품 통일(261006 적용 완료). 이미지 98장 `web/ssd-pdp/u1/`.
- 가격(261006 최종): 롱티 23,000 / 홀터넥 28,000 / 쇼츠 25,000 / 셋업 47,700(53,000 의 10%). PAIR YOUR SET 조합 스크립트에 가격 문자열이 하드코딩돼 있어 가격이 바뀌면 같이 고친다. 셋업 정가 스크립트는 `SETS` 할인율, `LABEL` 퍼센트.
- 로그인/가입 C안(스플릿 화보) 적용, 최근 사용 배지는 버튼 안 반투명 알약. Apple 로그인 제외.
- 카페24 PRO 해지 신청(261009). 리뷰는 4번 게시판 기반으로 직접 디자인하기로(해지 확정 후 진행). 알파푸시는 무료 유지, 캠페인 5개 Off(나중에 재설계 원함).
- 상세설명 디자인 탐색은 코드보다 피그마가 효율적이라는 판단이 있었으나, 결국 코드 생성기로 확정 구현했다. 완성도의 병목은 레이아웃보다 실촬영 사진.
- 주문서 페이지, 로그인 계열은 layout.html 이 아니라 각 페이지 파일에 붙인다.
