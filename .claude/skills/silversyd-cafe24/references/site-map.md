## 주요 화면과 담당 코드

- **메인:** 히어로 > SHOP BY LINE > NEW ARRIVALS > POPULAR > 2단 배너 > SHOP BY COLOR > SHAPE UP SET > PAIR YOUR SET > BEST > TENSION FIT. `html` 태그 자체에 `ssd-main` 클래스가 붙는다(**`html .ssd-main` 선택자는 절대 매칭 안 됨**, `html.ssd-main` 으로).
- **상품카드:** 호버 퀵애드, 색상 스와치(칩 클릭 시 그 자리에서 색 전환), 호버 사진 크로스페이드, 스켈레톤.
- **카테고리:** 짐샤크형 좌측 정렬 사이드바, 모바일 2열, 1024 이하 BEST/상의/하의/셋업/ALL 라인 탭, PAIR YOUR SET 모바일 2열.
- **상품 상세:** 짐샤크형 2단, 모바일 갤러리 스와이프+점(첫 방문 1회 밀림 안내, 3초 무터치 자동 이동), 컬러칩, 사이즈 버튼 영문/국문 2줄, 혜택 박스(`.ssd-pdp__perks`), 접이식(`.ssd-pdp__folds`, 마지막 줄은 배송/교환/환불 안내 링크).
- **상세설명(에디봇):** 공통 u1 골격, 상품별 `sd--{상품}` 본문. 섹션 순서는 `design-and-copy.md`.
- **헤더:** PC 한 줄 64px, 스크롤 시 투명(매니저 요청). 모바일/태블릿 스크롤 시 흰 배경. 모바일 헤더에 장바구니 없음(메뉴, 검색뿐).
- **푸터:** 검정 배경, 링크 4단, 무통장 안내 숨김.
- **로그인/가입:** SSD AUTH 블록(member/login.html, agreement.html, join.html 맨 아래). C안 스플릿(화보 + 폼), SNS 카카오(카카오싱크)/네이버/구글. 로그인은 기존 카페24 버튼을 옮기고(onclick 유지), 가입 페이지는 새 버튼(Kakao SDK v1, init 후에만 Kakao.Auth 생김). 비회원 주문조회(`?noMemberOrder`)와 비회원 구매(`?noMember=1`) 분기 있음. `#wrap overflow:hidden` 때문에 sticky 무효.
- **주문서/주문완료:** 별도 레이아웃. 카페24 기본 CSS `h1.xans-layout-logotop{margin-left:40px}` 가 뒤로가기 화살표와 겹치는 문제를 페이지별 CSS 로 수정.
- **리뷰:** 원본은 4번 게시판(board_no=4). 카페24 PRO 해지 신청(261009) 후 프로리뷰 위젯(poxo iframe)이 빠지면 기본 게시판 화면이 다시 보일 예정. 게시판 글 화면에는 구매 옵션(사이즈) 데이터가 없다.
- **팝업:** 「지금 가장 핫한 상품」, 1,000원 쿠폰은 알파푸시 온사이트 캠페인(261009 전부 Off). 무료 플랜은 캠페인 1개.
- **스키마:** 카페24 기본 ProductGroup/Product + 코드 B 보강(가격 숫자 정규화, InStock, shippingDetails, 반품정책). 상세 갤러리 alt 는 코드 C 가 채움. 롱티 상품 이미지 Alt 가 쇼츠 문구로 잘못 들어가 있음(관리자 SEO 칸).
