# 실버시드 카페24 개편 작업

실버시드는 고중량 운동을 하는 2030 여성을 위한 짐웨어 브랜드다. 사이트는 카페24 스마트디자인 반응형 단일 스킨(basic) 위에 우리가 만든 코드 블록 약 30개를 `layout.html` 에 쌓아 올린 구조다. 261009 까지 74차에 걸쳐 수정했고, 그 과정에서 확정된 규칙과 시행착오를 담았다.

## 먼저 읽을 것 (필요한 것만)

| 상황 | 읽을 문서 |
|---|---|
| 코드를 고치거나 새로 넣는다 | `references/cafe24-rules.md` (필수, 편집기 함정) |
| 어떤 화면이 어디서 그려지는지, 상품번호, 블록 목록 | `references/site-map.md` |
| 상세설명, 시안, 문구 작업 | `references/design-and-copy.md` |
| 예전 결정의 이유, 비슷한 버그 전례 | `references/history.md` |
| 지금 남은 일, 미결 사항 | `references/open-items.md` (261009 기준 스냅샷) |

기록은 261009 기준이다. 사이트는 계속 바뀌므로 **사실을 쓰기 전에 라이브 페이지로 다시 확인**한다. 특히 블록 목록, 가격, 옵션명은 `scripts/list_blocks.py` 와 라이브 HTML 로 매번 확인할 것.

## 작업 흐름

1. **재현부터.** 고객 증상을 라이브 페이지에서 직접 재현한다. 모바일(390, iPhone UA)과 PC(1300) 둘 다. "나만 그런가"라는 질문에는 재현 결과로 답한다.
2. **원인을 코드 단위로 특정.** 라이브 HTML 을 내려받아 해당 요소, 담당 블록(`<!-- SILVERSYD 이름 시작 -->`), 스킨 CSS 를 찾는다. 모바일과 PC 가 다른 DOM 을 쓰는 곳이 많다(예: 상세 하단 탭은 1024 이하에서 `#tabProduct` 탭 전환, PC 는 펼침).
3. **수정 코드 작성.** 기존 블록을 고치기보다 **마지막 블록 끝 주석 뒤에 새 블록을 덧붙인다.** 블록 이름은 `<!-- SILVERSYD 이름 시작/끝 -->`. 기존 코드 한 줄을 바꿔야 하면 특수문자 없는 한 줄 앵커로 찾기/바꾸기.
4. **금지 문자 검사.** `python3 scripts/check_forbidden.py 블록파일` 이 0 이어야 전달한다.
5. **라이브 주입 검증.** `python3 scripts/live_check.py` 로 실제 페이지에 코드를 넣고 390/800/1300 폭, 필요하면 WebKit 까지 확인한다. 클릭 동작은 `--click` 으로.
6. **전달.** `python3 scripts/make_guide.py` 로 복사 버튼이 달린 단독 HTML 가이드를 만든다. 채팅이나 마크다운으로 코드를 주지 않는다(자동 링크로 깨짐). 파일명은 `NN_주제.html`(다음 차수 번호).
7. **적용 확인.** 사용자가 "적용했어" 하면 `python3 scripts/verify_applied.py URL 블록파일` 로 라이브 코드가 원본과 같은지 확인하고, 주입 없이 `live_check.py` 를 다시 돌린다.

## 환경별 차이

- **Claude Code(로컬):** 위 흐름 전부 가능. playwright 가 없으면 `pip install playwright && python3 -m playwright install chromium webkit`.
- **claude.ai 웹:** 코드 실행 환경에서 외부 사이트 접속이 막혀 있을 수 있다. 이때는
  - 사용자에게 문제 페이지의 HTML(브라우저 "페이지 소스 보기" 전체 복사, 또는 저장한 .html 파일)을 받아 분석한다.
  - `check_forbidden.py`, `make_guide.py` 는 오프라인으로 돌아간다. 가이드 HTML 은 파일로 만들어 내려받게 한다.
  - 라이브 검증을 못 했으면 **못 했다고 분명히 말하고**, 사용자가 확인할 항목(폭, 눌러볼 곳, 기대 결과)을 구체적으로 적어 준다.

## 꼭 지킬 원칙

- **편집기 코드 변조:** `$` `?>` `</head` `</body` `http` 를 코드에 쓰지 않는다. jQuery `$` 대신 `document.querySelector`. 정규식 안에 태그 글자 금지. 자세한 이유는 `references/cafe24-rules.md`.
- **찾기 앵커:** 편집기 검색은 여러 줄, 괄호, 대괄호, 역슬래시, 들여쓰기가 섞인 줄을 못 찾는다. 주석 한 줄이 가장 안전하다.
- **스킨을 이기는 CSS 는 body 쪽에.** head 인라인 style 은 스킨 CSS 보다 먼저 적용된다.
- **주입형 스크립트는 중복 방지.** 기존 블록이 MutationObserver 로 다시 그리는 곳이 많다. 이미 처리했으면 건드리지 않는 가드, 같은 요소가 두 번 생기면 하나만 남기는 정리를 같이 넣는다.
- **캐시 키.** 메인 카드 스크립트는 sessionStorage 10분 캐시를 쓴다. 상품 번호 목록을 바꾸면 캐시 키 버전도 올린다.
- **추측 금지.** 가격, 소재, 판매량, 후기, 모델 정보 같은 사실은 지어내지 않는다. 가짜 고객 후기는 쓰지 않는다. 모르면 자리표시를 두고 사용자에게 요청한다.
- **사용자가 직접 고친 파일이 기준.** 다시 생성해서 덮어쓰지 말고, 수정분만 옮긴다.
- **시안은 고정 파일에 덮어쓰기.** `주제_시안_최신.html` 하나를 계속 갱신한다. 시안은 아티팩트가 아니라 단독 실행 HTML(charset, viewport, 이미지 data URI)로 저장하고 경로를 알려 준다.
- **보고는 결과로.** "확인 부탁드립니다"로 검증을 떠넘기지 않는다. 확인한 것과 못 한 것을 나눠 말한다.

## 문장 규칙 (산출물, 채팅 모두)

- 가로 대시(—)와 중간점(·) 금지. 쉼표, 괄호, "와/및"으로 푼다.
- 고객 화면 문구는 고객이 실제 할 법한 짧고 담백한 말. AI 번역투, 멋부린 은유, 과장 금지. 자세한 기준은 `references/design-and-copy.md`.
- 사용자에게 하는 설명은 습니다체, 원인과 바뀌는 동작을 먼저.

## 스크립트

| 파일 | 용도 |
|---|---|
| `scripts/check_forbidden.py FILE...` | 편집기가 변조하는 문자열 개수. 전부 0 이어야 전달 |
| `scripts/list_blocks.py URL_or_FILE [--get 이름] [--mobile]` | 라이브 페이지의 블록 순서 목록, 블록 하나 추출 |
| `scripts/decode_optimizer.py URL_or_FILE` | 카페24 optimizer 번들 안의 CSS/JS 파일 순서 복원 |
| `scripts/live_check.py URL [옵션]` | 실제 페이지 열기, 코드 주입, 클릭, 넘침/깨진 이미지/오류 측정, 캡처 |
| `scripts/verify_applied.py URL BLOCK_FILE` | 사용자가 붙인 코드가 원본과 같은지 비교 |
| `scripts/make_guide.py spec.json OUT.html` | 복사 버튼 찾기/바꾸기 가이드 생성 (`assets/guide_example.json` 참고) |
